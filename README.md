# Trabajo Práctico: Sistema de Ventas en Blazor

Aplicación web full-stack desarrollada en **.NET 10** con **Blazor Server** y **Entity Framework Core**. Este proyecto implementa un sistema de gestión con operaciones CRUD completas y relaciones Maestro-Detalle.

## Tecnologías Utilizadas

* **Frontend & Backend:** C# 12, .NET 10, Blazor Server
* **ORM:** Entity Framework Core
* **Base de Datos:** SQL Server (Alojada en SmarterASP)
* **Diseño UI:** HTML5, CSS3, Bootstrap 5

## ✨ Características Principales

* **Gestión de Clientes:** Alta, baja, modificación y listado de clientes.
* **Gestión de Productos:** Control de inventario, precios y stock.
* **Registro de Ventas (Maestro-Detalle):** 
  * Formulario interactivo en tiempo real para agregar productos al carrito.
  * Cálculo dinámico de subtotales y total final.
  * Validación estricta de stock antes de confirmar la compra.
* **Historial de Operaciones:** Listado detallado de comprobantes emitidos.
